# 🧮 Amallar Bajaruvchi Dastur

C# tilida yozilgan konsol dasturi bo'lib, foydalanuvchidan 2 ta qiymat qabul qilib **Arifmetik** va **Geometrik** amallarni bajaradi.

## 📋 Dastur imkoniyatlari

Dastur ishga tushganda 2 ta bo'lim taklif etiladi:

### 1️⃣ Arifmetik amallar

| Amal | Formula |
|------|---------|
| 💰 Protsent farqi | `((b - a) / a) * 100` |
| 📊 Arifmetik o'rtacha | `(a + b) / 2` |
| 📊 Geometrik o'rtacha | `√(a * b)` |

### 2️⃣ Geometrik amallar

| Amal | Formula |
|------|---------|
| 📐 Uchburchak gipotenuzasi | `√(a² + b²)` |
| 📐 Uchburchak yuzasi | `(a * b) / 2` |
| 🔌 Parallel qarshilik | `(a * b) / (a + b)` |
